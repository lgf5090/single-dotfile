# Tmux 配置说明文档

## 概述

本配置基于 [Oh my tmux!](https://github.com/gpakosz/.tmux) 项目，这是一个功能丰富、美观且易于配置的 tmux 配置框架。配置分为两个主要文件：

- `tmux.conf` - 主配置文件（不应修改）
- `tmux.conf.local` - 本地自定义配置文件（用户可修改）

## 文件结构

```
stow/tmux/.config/tmux/
├── tmux.conf          # 主配置文件（只读）
└── tmux.conf.local    # 本地配置文件（可修改）
```

## 主要特性

### 1. 基础设置

#### 终端支持
- **256色支持**: 自动检测并启用 256 色终端支持
- **24位真彩色**: 支持 RGB 真彩色显示
- **扩展键支持**: 支持 Control + Shift 组合键

#### 前缀键配置
- **主前缀键**: `Ctrl-b` (默认)
- **辅助前缀键**: `Ctrl-a` (GNU Screen 兼容)

#### 基本优化
- **历史记录**: 5000 行历史记录
- **响应速度**: 优化了按键响应时间
- **UTF-8支持**: 完整的 UTF-8 字符支持

### 2. 窗口和面板管理

#### 窗口编号
- 窗口编号从 1 开始（而非 0）
- 面板编号从 1 开始
- 自动重新编号窗口

#### 窗口行为
- 自动重命名窗口以反映当前程序
- 设置终端标题
- 监控窗口活动

#### 面板分割
- **水平分割**: `前缀键 + -`
- **垂直分割**: `前缀键 + _`

### 3. 导航快捷键

#### 会话导航
- **创建新会话**: `前缀键 + Ctrl-c`
- **查找会话**: `前缀键 + Ctrl-f`
- **切换到上一个会话**: `前缀键 + BTab`

#### 面板导航
- **向左移动**: `前缀键 + h`
- **向下移动**: `前缀键 + j`
- **向上移动**: `前缀键 + k`
- **向右移动**: `前缀键 + l`
- **交换面板**: `前缀键 + >` 或 `前缀键 + <`

#### 面板调整
- **向左扩展**: `前缀键 + H`
- **向下扩展**: `前缀键 + J`
- **向上扩展**: `前缀键 + K`
- **向右扩展**: `前缀键 + L`

#### 窗口导航
- **上一个窗口**: `前缀键 + Ctrl-h`
- **下一个窗口**: `前缀键 + Ctrl-l`
- **交换窗口**: `前缀键 + Ctrl-Shift-H/L`
- **最后活动窗口**: `前缀键 + Tab`

### 4. 复制模式

#### 进入复制模式
- **进入复制模式**: `前缀键 + Enter`

#### 复制模式快捷键（Vi 风格）
- **开始选择**: `v`
- **矩形选择**: `Ctrl-v`
- **复制并退出**: `y`
- **取消**: `Escape`
- **行首**: `H`
- **行尾**: `L`

#### 剪贴板集成
支持多种系统剪贴板：
- **Linux X11**: xsel 或 xclip
- **Linux Wayland**: wl-copy
- **macOS**: pbcopy
- **Windows**: clip.exe

### 5. 主题配置

#### 颜色方案
配置使用 17 种预定义颜色：
- `colour_1` - `colour_17`: 深灰、灰、浅灰、蓝、黄、粉、绿、红、白等

#### 状态栏样式
- **左侧状态栏**: 显示会话名称和系统运行时间
- **右侧状态栏**: 显示电池状态、时间、日期、用户名和主机名
- **窗口状态**: 不同状态的窗口有不同的颜色标识

#### 面板边框
- **普通面板**: 灰色边框
- **活动面板**: 蓝色边框
- **特殊状态**: 复制模式（黄色）、同步模式（红色）

### 6. 电池显示

#### 电池信息
- **电池百分比**: 显示剩余电量百分比
- **电池状态**: 充电（↑）或放电（↓）图标
- **电池条**: 可视化电池电量条

#### 电池条样式
- **符号**: 实心方块（◼）和空心方块（◻）
- **调色板**: 渐变色彩（从红到绿）
- **长度**: 自动调整或固定长度

### 7. 系统信息显示

#### 运行时间
- **年**: `#{uptime_y}`
- **天**: `#{uptime_d}`
- **小时**: `#{uptime_h}`
- **分钟**: `#{uptime_m}`
- **秒**: `#{uptime_s}`

#### 网络和用户信息
- **用户名**: 本地和 SSH 用户名
- **主机名**: 本地和 SSH 主机名
- **负载平均值**: 系统负载信息

### 8. 插件支持

#### TPM（Tmux Plugin Manager）
- **自动安装**: 启动时自动安装插件
- **自动更新**: 重载配置时自动更新插件
- **插件管理**: 支持安装、更新、卸载插件

#### 插件快捷键
- **安装插件**: `前缀键 + I`
- **更新插件**: `前缀键 + u`
- **卸载插件**: `前缀键 + Alt + u`

### 9. 高级功能

#### 鼠标支持
- **切换鼠标模式**: `前缀键 + m`
- 支持鼠标选择面板、调整大小、滚动等

#### URL 扫描
- **URL 扫描**: `前缀键 + U`
- 支持 urlscan 或 urlview 工具

#### Facebook PathPicker
- **文件路径选择**: `前缀键 + F`
- 集成 Facebook PathPicker 工具

#### 面板最大化
- **最大化面板**: `前缀键 + +`
- 临时最大化当前面板

### 10. 配置选项详解

#### 会话和窗口行为
```bash
# 新会话提示输入名称
tmux_conf_new_session_prompt=false

# 新会话保持当前路径
tmux_conf_new_session_retain_current_path=false

# 新窗口保持当前路径
tmux_conf_new_window_retain_current_path=false

# 新窗口尝试重连 SSH 会话
tmux_conf_new_window_reconnect_ssh=false

# 新面板保持当前路径
tmux_conf_new_pane_retain_current_path=true

# 新面板尝试重连 SSH 会话
tmux_conf_new_pane_reconnect_ssh=false
```

#### 显示设置
```bash
# 24位颜色支持
tmux_conf_24b_colour=auto

# 主题启用
tmux_conf_theme=enabled

# 高亮聚焦面板
tmux_conf_theme_highlight_focused_pane=false

# 面板边框样式
tmux_conf_theme_pane_border_style=thin
```

#### 剪贴板设置
```bash
# 复制到系统剪贴板
tmux_conf_copy_to_os_clipboard=false
```

## 自定义变量

配置支持自定义变量功能，可以在状态栏中显示自定义信息：

### 示例自定义函数
```bash
# 天气信息
weather() {
    curl -f -s -m 2 'wttr.in?format=3' || printf '\n'
    sleep 900
}

# 网络状态
online() {
    ping -c 1 1.1.1.1 >/dev/null 2>&1 && printf '✔' || printf '✘'
}

# 外网 IP
wan_ip_v4() {
    curl -f -s -m 2 -4 ifconfig.me
    sleep 300
}
```

## 兼容性

### 系统支持
- **Linux**: 完整支持
- **macOS**: 完整支持
- **Windows**: 通过 WSL 或 Cygwin 支持
- **FreeBSD/OpenBSD**: 基本支持

### Tmux 版本要求
- **最低版本**: tmux 2.6+
- **推荐版本**: tmux 3.0+
- **最新特性**: tmux 3.2+

### 依赖工具
- **必需**: perl, sed, awk
- **可选**: xsel/xclip (Linux), urlscan/urlview, fpp

## 性能优化

### 状态栏更新
- 状态栏每 10 秒更新一次
- 电池信息每 60 秒更新一次
- 系统信息按需更新

### 内存使用
- 历史记录限制为 5000 行
- 插件按需加载
- 后台进程优化

## 故障排除

### 常见问题
1. **颜色显示异常**: 检查终端是否支持 256 色或真彩色
2. **快捷键不工作**: 确认前缀键设置正确
3. **插件安装失败**: 检查网络连接和 git 配置
4. **电池信息不显示**: 确认系统支持电池信息获取

### 调试方法
1. 检查 tmux 版本: `tmux -V`
2. 查看配置错误: `tmux source-file ~/.config/tmux/tmux.conf`
3. 检查插件日志: `~/.tmux/plugins/tpm_log.txt`

## 更新和维护

### 配置更新
- 主配置文件 `tmux.conf` 不应手动修改
- 所有自定义设置应在 `tmux.conf.local` 中进行
- 使用 `前缀键 + r` 重载配置

### 插件管理
- 插件会在启动和重载时自动更新
- 可以通过设置禁用自动更新
- 支持手动管理插件

这个配置提供了一个功能丰富、美观且高度可定制的 tmux 环境，适合各种使用场景和用户需求。
