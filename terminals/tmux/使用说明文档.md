# Tmux 使用说明文档

## 快速开始

### 安装和启动

1. **启动 tmux**
   ```bash
   tmux
   ```

2. **创建命名会话**
   ```bash
   tmux new-session -s 工作会话
   ```

3. **连接到现有会话**
   ```bash
   tmux attach-session -t 工作会话
   ```

4. **列出所有会话**
   ```bash
   tmux list-sessions
   ```

## 基础操作指南

### 前缀键说明

所有 tmux 命令都需要先按前缀键，然后按具体的功能键：
- **主前缀键**: `Ctrl + b`
- **辅助前缀键**: `Ctrl + a` (GNU Screen 兼容)

> 💡 **提示**: 下文中 `前缀键` 指的是 `Ctrl + b` 或 `Ctrl + a`

### 会话管理

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `前缀键 + Ctrl + c` | 创建新会话 | 创建一个新的 tmux 会话 |
| `前缀键 + Ctrl + f` | 查找会话 | 通过名称查找并切换会话 |
| `前缀键 + BTab` | 切换会话 | 切换到上一个活动会话 |
| `前缀键 + d` | 分离会话 | 断开当前会话但保持运行 |
| `前缀键 + $` | 重命名会话 | 为当前会话设置新名称 |

### 窗口管理

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `前缀键 + c` | 创建新窗口 | 在当前会话中创建新窗口 |
| `前缀键 + &` | 关闭窗口 | 关闭当前窗口（需确认） |
| `前缀键 + ,` | 重命名窗口 | 为当前窗口设置新名称 |
| `前缀键 + Tab` | 最后窗口 | 切换到上一个活动窗口 |
| `前缀键 + Ctrl + h` | 上一个窗口 | 切换到前一个窗口 |
| `前缀键 + Ctrl + l` | 下一个窗口 | 切换到后一个窗口 |
| `前缀键 + 0-9` | 选择窗口 | 直接跳转到指定编号的窗口 |
| `前缀键 + w` | 窗口列表 | 显示所有窗口的交互式列表 |

| `前缀键 + k` | 向上移动 | 移动到上方面板 |

## 实用工作流程

### 开发环境设置

1. **创建开发会话**
   ```bash
   tmux new-session -s 开发环境
   ```

2. **设置多面板布局**
   - `前缀键 + -` 创建水平分割（编辑器上方，终端下方）
   - `前缀键 + _` 在下方面板创建垂直分割（终端和日志）

3. **面板用途分配**
   - 上方面板：代码编辑器（vim/nvim）
   - 左下面板：命令行操作
   - 右下面板：日志监控或测试

### 系统监控设置

1. **创建监控会话**
   ```bash
   tmux new-session -s 系统监控
   ```

2. **多窗口监控**
   - 窗口 1：系统资源监控（htop）
   - 窗口 2：网络监控（iftop）
   - 窗口 3：日志监控（tail -f）
   - 窗口 4：进程监控（ps）

### 远程服务器管理

1. **SSH 会话管理**
   ```bash
   tmux new-session -s 服务器管理
   ```

2. **多服务器连接**
   - 每个窗口连接不同服务器
   - 使用窗口重命名标识服务器
   - 利用面板分割同时监控多个服务

## 状态栏信息解读

### 左侧状态栏
```
❐ 会话名称 | ↑ 运行时间
```
- **❐**: 会话图标
- **会话名称**: 当前 tmux 会话的名称
- **↑**: 系统运行时间图标
- **运行时间**: 显示系统已运行的时间（天、小时、分钟）

### 右侧状态栏
```
前缀指示器 鼠标指示器 配对指示器 同步指示器 电池状态 时间 日期 用户名 主机名
```

#### 指示器说明
- **⌨**: 前缀键已按下
- **↗**: 鼠标模式已启用
- **⚇**: 多客户端连接
- **⚏**: 面板同步模式
- **!**: root 用户警告

#### 电池信息
- **↑/↓**: 充电/放电状态
- **百分比**: 剩余电量百分比
- **电池条**: 可视化电量显示

### 窗口状态
- **数字**: 窗口编号
- **名称**: 窗口名称
- **!**: 窗口有警告
- **Z**: 窗口面板已最大化
- **高亮**: 当前活动窗口

## 自定义配置

### 修改本地配置

编辑 `~/.config/tmux/tmux.conf.local` 文件：

```bash
# 启用鼠标支持
set -g mouse on

# 修改前缀键为 Ctrl+a
set -gu prefix2
unbind C-a
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# 增加历史记录
set -g history-limit 10000

# 状态栏位置
set -g status-position top
```

### 添加自定义快捷键

```bash
# 快速分割面板
bind | split-window -h -c '#{pane_current_path}'
bind - split-window -v -c '#{pane_current_path}'

# 快速重载配置
bind R source-file ~/.config/tmux/tmux.conf \; display "配置已重载!"

# 同步面板输入
bind S setw synchronize-panes
```

### 插件配置

在 `tmux.conf.local` 中添加插件：

```bash
# 常用插件
set -g @plugin 'tmux-plugins/tmux-resurrect'    # 会话恢复
set -g @plugin 'tmux-plugins/tmux-continuum'    # 自动保存
set -g @plugin 'tmux-plugins/tmux-cpu'          # CPU 监控
set -g @plugin 'tmux-plugins/tmux-battery'      # 电池信息

# 插件配置
set -g @continuum-restore 'on'                  # 启动时自动恢复
set -g @resurrect-capture-pane-contents 'on'    # 保存面板内容
```

## 故障排除

### 常见问题解决

1. **快捷键不响应**
   - 确认前缀键设置正确
   - 检查是否与其他程序冲突
   - 重新加载配置：`前缀键 + r`

2. **颜色显示异常**
   - 检查终端颜色支持：`echo $TERM`
   - 设置正确的终端类型：`export TERM=screen-256color`

3. **鼠标不工作**
   - 启用鼠标支持：`前缀键 + m`
   - 检查终端是否支持鼠标

4. **复制粘贴问题**
   - 确认系统剪贴板工具已安装
   - Linux: xsel, xclip, wl-copy
   - macOS: pbcopy (内置)
   - Windows: clip.exe

5. **插件安装失败**
   - 检查网络连接
   - 确认 git 已安装并配置
   - 手动安装：`前缀键 + I`

### 性能优化

1. **减少状态栏更新频率**
   ```bash
   set -g status-interval 30  # 30秒更新一次
   ```

2. **限制历史记录**
   ```bash
   set -g history-limit 5000  # 限制为5000行
   ```

3. **禁用不需要的功能**
   ```bash
   set -g visual-activity off  # 禁用活动通知
   set -g monitor-activity off # 禁用活动监控
   ```

## 进阶技巧

### 会话模板

创建会话启动脚本：

```bash
#!/bin/bash
# 创建开发环境会话
tmux new-session -d -s 开发环境

# 创建窗口
tmux new-window -t 开发环境:1 -n '编辑器'
tmux new-window -t 开发环境:2 -n '终端'
tmux new-window -t 开发环境:3 -n '服务器'

# 分割面板
tmux split-window -h -t 开发环境:2
tmux split-window -v -t 开发环境:2.1

# 启动程序
tmux send-keys -t 开发环境:1 'vim' Enter
tmux send-keys -t 开发环境:3 'ssh server' Enter

# 连接到会话
tmux attach-session -t 开发环境
```

### 键盘映射

创建更直观的快捷键：

```bash
# 使用 Alt 键快速切换窗口
bind -n M-1 select-window -t 1
bind -n M-2 select-window -t 2
bind -n M-3 select-window -t 3

# 使用 Alt + 方向键切换面板
bind -n M-Left select-pane -L
bind -n M-Right select-pane -R
bind -n M-Up select-pane -U
bind -n M-Down select-pane -D
```

### 自动化脚本

使用 tmux 命令行进行自动化：

```bash
# 批量创建会话
for project in web api mobile; do
    tmux new-session -d -s $project
    tmux send-keys -t $project "cd ~/projects/$project" Enter
done

# 批量执行命令
tmux list-sessions -F '#{session_name}' | \
    xargs -I {} tmux send-keys -t {} 'git status' Enter
```

### 新增的便捷快捷键

本配置在保留所有原有功能的基础上，新增了以下便捷快捷键：

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `前缀键 + Ctrl+x` | 快速关闭面板 | 无需确认，直接关闭当前面板 |
| `前缀键 + Ctrl+q` | 快速关闭窗口 | 无需确认，关闭当前窗口的所有面板 |

### 与原有快捷键的对比

| 操作 | 原有快捷键 | 新增快捷键 | 区别 |

| 关闭窗口 | `前缀键 + &` | `前缀键 + Ctrl+q` | 新增版本无需确认 |

### 保留的原有功能

所有原有快捷键功能完全保留：

| 快捷键 | 功能 | 状态 |
|--------|------|------|
| `前缀键 + w` | 显示窗口选择树 | ✅ 完全保留 |
| `前缀键 + q` | 显示面板编号 | ✅ 完全保留 |
| `前缀键 + x` | 关闭面板（需确认） | ✅ 完全保留 |
| `前缀键 + &` | 关闭窗口（需确认） | ✅ 完全保留 |

### 使用场景

#### 快速清理工作区
当您有多个分屏面板时：
1. **逐个关闭不需要的面板**: 移动到面板 → `前缀键 + Ctrl+x`
2. **一次性关闭所有面板**: `前缀键 + Ctrl+q`

#### 开发环境管理
在开发过程中快速调整窗口布局：
```bash
# 场景：四分屏开发环境
# 上左：编辑器  上右：文档
# 下左：终端    下右：日志

# 完成开发后，快速关闭日志面板
前缀键 + Ctrl+x  # 在日志面板中执行

# 或者直接关闭整个开发窗口
前缀键 + Ctrl+q
```

### 自定义更多快捷键

如果您想添加更多自定义快捷键，可以编辑 `~/.config/tmux/tmux.conf.local` 文件：

```bash
# 在 "# custom key bindings for pane management" 部分添加

# 示例：添加更多便捷操作
bind C-r respawn-pane -k              # Ctrl+r 重启面板
bind C-z resize-pane -Z               # Ctrl+z 最大化/还原面板
bind C-s setw synchronize-panes       # Ctrl+s 同步面板输入

# 示例：快速分割面板
bind | split-window -h -c '#{pane_current_path}'    # | 垂直分割
bind - split-window -v -c '#{pane_current_path}'    # - 水平分割

# 示例：快速导航
bind -n M-h select-pane -L            # Alt+h 向左切换面板
bind -n M-j select-pane -D            # Alt+j 向下切换面板
bind -n M-k select-pane -U            # Alt+k 向上切换面板
bind -n M-l select-pane -R            # Alt+l 向右切换面板
```
